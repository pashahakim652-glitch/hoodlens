# HoodLens Web MVP

Frontend prototype for HoodLens — token intelligence for Robinhood Chain.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Current state
- Landing page
- Token scanner interaction
- Risk score UI
- Risk signals
- Holder analysis
- Contract analysis
- Responsive design
- Demo/mock data only

## Next build step
Connect scanner to Robinhood Chain RPC, Blockscout/indexer data, Pons V1/V2 detection and real risk-engine logic.
